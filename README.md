## 이게 왜 필요한가요

인스타그램 DM, 디스코드 초대, 카카오톡 오픈채팅으로 낯선 링크를 받는 건
청소년에게 일상적인 일입니다. 기프트카드 당첨, 팔로워 늘려주기, 로그인
화면을 위장한 계정 탈취 페이지처럼요. 문제는 눌러보기 전엔 그게 진짜인지
가짜인지 알 방법이 마땅치 않다는 겁니다.

그리고 위험이 꼭 "해킹"만 있는 것도 아닙니다. 도박, 성인물, 불법 웹툰처럼
계정이 털리진 않아도 국내 법률상 접속 자체가 제한되는 사이트도 있습니다.
**CheckLink**는 이 두 가지를 구분해서 알려줍니다.

**CheckLink**는 링크를 붙여넣기만 하면:

1. **검사한다** — VirusTotal(보안 엔진 대조)과 urlscan.io(격리된 가상
   브라우저로 실제 접속)를 이용해 그 링크의 실체를 파악합니다. 유튜브·구글처럼
   urlscan.io가 정책상 스캔을 막는 사이트는 microlink.io로 화면만 보조로 확인합니다.
2. **설명한다** — "38개 엔진 중 4개 malicious" 같은 전문 용어 대신,
   "이 사이트는 만들어진 지 3일밖에 안 됐어요"처럼 중학생도 이해할 수 있는
   말로 왜 위험한지(또는 안전한지) 알려줍니다. 계정 탈취 위험(🔴위험/🟡주의)과
   법적으로 접속이 제한되는 콘텐츠(🟠접속 제한)는 서로 다른 문제이므로 다른
   배지와 다른 설명으로 보여줍니다.
3. **대처법을 안내한다** — 이미 링크를 눌러버렸다면, 먼저 실제 피해가 있었는지
   확인한 뒤 어느 플랫폼에서 무엇을 했는지에 따라 지금 순서대로 뭘 해야
   하는지 체크리스트로 보여주고, 필요하면 112·사이버범죄 신고시스템 같은
   신고·상담 창구도 안내합니다.

## 누구를 위한 서비스인가요

- **1차 대상**: 중·고등학생 (13~18세)
- **2차 대상**: 자녀가 받은 링크를 대신 확인해보고 싶은 보호자

로그인이나 회원가입 없이 바로 쓸 수 있고, 검사한 URL은 저장하지 않습니다.
이미 겁먹었거나 피해를 본 사람이 볼 수도 있는 화면이라, 책망하거나
겁주는 톤을 쓰지 않습니다.

## 동작 원리

링크 하나가 결과 화면까지 가는 과정은 이렇게 나뉩니다.

```
              사용자가 링크 입력
                     │
                     ▼
    ① URL 정규화·검증          lib/normalize.ts
       (localhost·사설 IP 등은 여기서 바로 걸러냄)
                     │
                     ▼
    ② 위협 데이터 수집 — 병렬 실행
        ┌────────────────────┬────────────────────┐
        ▼                                          ▼
   VirusTotal                                urlscan.io
   70여 개 보안 엔진·카테고리                    격리된 가상 브라우저로
   대조 (정적 분석)                             실제 접속 (동적 분석)
        │                                          │
        │                          urlscan.io가 정책상 막힌 경우(예: 유튜브)만
        │                          → microlink.io로 스크린샷만 보조 조회
        └────────────────────┬────────────────────┘
                              ▼
    ③ 위험도 점수 계산          lib/score.ts (순수 함수)
       브랜드 사칭 여부, 불법 웹툰 사이트 이름 힌트까지 더해
       danger › caution › content_restricted › safe 우선순위로 판정 확정
                              │
                              ▼
    ④ (content_restricted일 때만) 고정 법적 고지 문구 생성
       "방송통신심의위원회 차단 대상" 문구는 표현이 흔들리면 안 되므로
       LLM을 거치지 않고 lib/score.ts가 그대로 만든다
                              │
                              ▼
    ⑤ 서사 설명 생성            lib/llm.ts (Claude API)
       확정된 점수·근거를 청소년이 이해할 말로 번역 (verdict는 뒤집지 못함)
                              │
                              ▼
    ⑥ (danger 판정 + 알림을 켠 사용자인 경우만) 위험 알림 발송
       lib/push.ts — 결과 응답을 기다리지 않고 비동기로 처리
                              │
                              ▼
            결과 화면 (🟢안전 / 🟡주의 / 🟠접속 제한 / 🔴위험)
```

핵심은 **순서**입니다. ③번(점수 계산)이 ⑤번(LLM 설명)보다 먼저 끝나 있고,
LLM은 ③번이 이미 내린 판정을 절대 뒤집지 못합니다. LLM에게 "이 링크
위험해?"라고 묻는 게 아니라, "이미 판정 났으니 이걸 사람 말로 옮겨줘"라고만
시키는 구조라, LLM이 근거 없이 "괜찮아 보여요"라고 잘못 말하는 환각 사고를
구조적으로 막습니다. LLM 호출이 실패해도 서비스가 멈추지 않도록, ③번이 만든
신호를 그대로 문장으로 옮기는 템플릿 폴백이 항상 준비돼 있습니다.

②번에서 그 링크에 **실제로 접속하는 건 저희 서버가 아니라 urlscan.io(또는
보조로 microlink.io)**입니다. 저희 코드에는 사용자가 입력한 URL에 직접
`fetch`를 날리는 부분이 어디에도 없습니다 — 그 사이트가 진짜 악성코드를
심어놨어도, 이미 검증된 외부 격리 환경이 대신 접속해줍니다. urlscan.io가
DNS 조회 자체에 실패하면(이미 차단됐거나 사라진 사이트) 그 사실 자체를
결과 화면에 담담하게 보여줍니다.

## 사용한 언어와 API

| 구성 요소 | 어떤 일을 하나요 |
|---|---|
| **TypeScript** | 전체 코드베이스의 언어. API 응답 스키마를 타입으로 고정해 잔버그를 컴파일 단계에서 잡습니다 |
| **Next.js 15 (App Router)** | 프론트엔드 화면과 백엔드(`app/api/scan`, `app/api/push/*`)를 한 프로젝트에서 처리 |
| **VirusTotal API** | 70여 개 보안 엔진·블랙리스트에 URL을 대조하는 **정적 분석**. "이미 알려진 위협인가?"와 사이트 카테고리(도박/성인물/불법복제 등)를 확인합니다 |
| **urlscan.io API** | 격리된 가상 브라우저로 URL에 **실제 접속**해 스크린샷, 리다이렉트 경로, 비밀번호 입력창 존재 여부, 도메인 생성일, 접속한 외부 도메인 수를 확인하는 **동적 분석**. 서버가 아니라 이 API가 접속을 대행합니다 |
| **microlink.io API** | urlscan.io가 정책적으로 차단하는 대형 사이트(유튜브·구글 등)일 때만 스크린샷을 보조로 조회하는 폴백. 이 역시 대상 URL에는 저희 서버가 아니라 microlink.io가 접속합니다 |
| **Anthropic Claude API (`claude-sonnet-5`)** | 위 API들이 모은 사실 데이터를 받아 청소년이 이해할 문장으로 번역. 위험도를 스스로 판단하지 않고, `lib/score.ts`가 이미 내린 판정을 설명만 합니다 |
| **Zod** | 외부 API 응답과 LLM 출력이 예상한 형태로 왔는지 런타임에 검증 |
| **Tailwind CSS** | 모바일 우선(375px 기준) 반응형 UI. 라이트/다크 모드 지원 |
| **PostgreSQL (`pg`)** | 위험 알림을 켠 브라우저의 푸시 구독 정보(endpoint/keys)만 저장하는 용도. 검사한 URL은 여기에도 절대 저장하지 않습니다 |
| **web-push + Service Worker** | 검사 결과가 danger(위험)로 확정되고 사용자가 알림을 켜둔 경우 브라우저 푸시 알림을 보냅니다 (`lib/push.ts`, `public/sw.js`) |
| **Vitest** | `lib/score.ts`, `lib/llm.ts`, `lib/rateLimit.ts`, urlscan 응답 파싱 등 핵심 로직 단위 테스트 |
| **Railway** | 배포 플랫폼. Next.js 서버가 그대로 실행됩니다 |

## 화면 구성

| 화면 | 내용 |
|---|---|
| 입력 | URL 하나만 붙여넣고 "검사하기" |
| 검사 중 | 경과 시간 기준으로 추정한 단계 표시(주소 확인 → 보안 데이터베이스 대조 → 가상 환경 접속 → 결과 정리) |
| 결과 | 🟢안전 / 🟡주의 / 🟠접속 제한 / 🔴위험 배지, (접속 제한인 경우 고정 법적 고지 문구), "무슨 사이트냐면..." 정체 설명, 블러 처리된 실제 스크린샷, 판단 근거, TIP, 위험·접속 제한인 경우 "이미 눌렀어요" 버튼 |
| 대처 | ① 실제로 피해(정보 유출·금전 피해)가 있었는지부터 확인 → 없으면 가벼운 자가 점검만 안내하고 종료 가능 → ② 플랫폼(인스타/디스코드/카카오톡/메시지/기타)과 한 행동(눌렀다/비밀번호 입력/앱 설치/사진 전송/송금, 복수 선택)을 고르면 → ③ 조합별 맞춤 체크리스트와 함께, 필요할 때는 112·사이버범죄 신고시스템(ECRM)·한국인터넷진흥원 118·청소년상담 1388·디지털성범죄피해자지원센터 같은 신고·상담 창구를 보여줌 |
| 설정 | 화면 우측 상단 톱니바퀴 → 라이트/다크 모드 전환, 위험 사이트 감지 시 푸시 알림 켜기/끄기 |

## 설계 원칙

- **판정은 코드가, 설명은 LLM이** — 위험도 점수는 `lib/score.ts`의 순수
  함수가 계산합니다. 보안 위험(danger) → 의심 신호(caution) → 법적 콘텐츠
  제한(content_restricted) → 안전(safe) 순으로 우선순위가 정해져 있고, LLM에게
  "이 URL이 위험한가?"를 묻지 않고 이미 나온 판정을 사람 말로 옮기는 역할만
  맡깁니다.
- **원본 페이지 콘텐츠를 LLM에 넣지 않는다** — 프롬프트 인젝션을 막기 위해
  urlscan.io/VirusTotal이 반환한 구조화된 필드값만 LLM에 전달합니다.
- **서버가 대상 URL에 직접 접속하지 않는다** — 실제 접속은 urlscan.io가,
  그리고 urlscan.io가 막힌 경우에만 microlink.io가 격리된 환경에서 대행합니다.
- **API 키는 서버 사이드에서만** — 클라이언트 번들에 노출되지 않습니다. 알림
  기능에 쓰이는 VAPID 공개키도 빌드 타임에 번들에 박아 넣지 않고, 요청 시점에
  서버에서 받아옵니다.
- **사용자가 입력한 URL은 로그·DB에 남기지 않습니다.** 알림 기능용
  PostgreSQL에도 브라우저의 푸시 구독 정보(endpoint/keys)만 저장되며, 검사한
  URL 자체는 어디에도 저장되지 않습니다.

자세한 배경과 요구사항은 [`PRD.md`](./PRD.md)를 참고하세요.

## 시작하기

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

`.env.local`에 채워야 하는 값:

| 변수 | 필수 여부 | 용도 |
|---|---|---|
| `URLSCAN_API_KEY` | 필수 | urlscan.io 동적 분석 |
| `VIRUSTOTAL_API_KEY` | 필수 | VirusTotal 정적 분석 |
| `ANTHROPIC_API_KEY` | 필수(없어도 서비스 자체는 동작) | Claude API 호출 실패/미설정 시 템플릿 폴백 설명으로 자동 대체 |
| `DATABASE_URL` | 선택 | 위험 알림 기능용 PostgreSQL 연결 문자열 |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | 선택 | 위 DB와 함께 있어야 브라우저 푸시 알림 기능이 동작. 없어도 검사 기능은 정상 동작하고 알림만 건너뜁니다 |

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

### 주요 명령어

```bash
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 검증 (커밋 전 필수)
npm test         # 단위 테스트 (vitest run)
npm run lint     # 린트
```
